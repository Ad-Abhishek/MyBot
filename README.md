## MyBot — Python Chatbot

MyBot is a beginner-friendly chatbot built with Python. It uses rule-based intent detection, text normalization, keyword matching, and fuzzy string matching to respond to user messages. It stores its knowledge in a JSON file and provides both a command-line interface and a desktop GUI built with Tkinter.

### Features

Interactive command-line conversation

Desktop graphical user interface using Tkinter

Predefined question-and-answer responses

Intent-based response generation

Text normalization and tokenization

Keyword and fuzzy string matching

Case-insensitive message handling

JSON-based knowledge storage

Multiple response variations

Error handling for missing or invalid knowledge files

Automated unit tests using Python's built-in unittest framework

### Requirements

Python 3

Git (optional, for version control)

RapidFuzz (for fuzzy string matching)

Tkinter is included with many standard Python installations. No separate installation is usually required.

### Installation

1. Clone the repository

git clone https://github.com/Ad-Abhishek/MyBot.git

2. Navigate to the project directory

cd MyBot

3. Create a virtual environment

python -m venv .venv

4. Activate the virtual environment

On Windows Command Prompt:

.venv\Scripts\activate.bat

On Windows PowerShell:

.\.venv\Scripts\Activate.ps1

5. Install dependencies

python -m pip install -r requirements.txt

### Usage

MyBot supports both a command-line interface and a desktop graphical interface.

Run the command-line chatbot

python main.py

Run the desktop GUI

python gui.py

The desktop interface allows you to enter messages, send them using the Send button or Enter key, view the conversation, and clear the displayed chat.

### Run Tests

Execute the automated unit tests using:

python -m unittest -v

The tests cover text normalization, tokenization, intent matching, fuzzy matching, unknown messages, and response generation.

### Current Limitations

Responses are predefined rather than generated by an AI language model.

Intent detection relies on manually defined patterns and text similarity.

The chatbot may fail to recognize questions expressed in unfamiliar ways.

Conversation history is not yet persisted between sessions.

The chatbot does not yet support document-based question answering.
